## 项目简介

DoShare 是一个面向本科生的数据集导航与学习共享平台。

在课程学习和项目实践中，学生常常面临以下问题：
- 数据集来源分散，难以查找
- 数据结构复杂，上手困难
- 缺乏配套的使用说明和分析指导

针对这些问题，DoShare 提供：

- 📊 数据集整合：汇集多领域高质量数据集  
- 🧭 分类与检索：提供清晰的数据集分类与导航  
- 📖 使用指导：包含字段说明、应用场景与基础分析案例  
- ⭐ 质量评估：通过评分机制筛选优质数据集  
- 🤖 智能问答：支持自然语言提问，提供分析思路与代码示例  
- 👥 学习社区：支持经验分享与问题交流  

通过以上功能，平台帮助用户从“找到数据”到“理解数据”再到“应用数据”，逐步完成数据分析学习过程。
